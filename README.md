# Expense Tracker

A simple Expense Tracker made with HTML, CSS & JavaScript. Track your income and expenses in Rs.

## Feature

- Add Income / Expense
- Live Balance, Income & Expense summary
- Delete transactions
- Data saved in browser with localStroage
- Currency in Rs (PKR)
- Custom scrollbar

## How to Use

1. Enter Description (e.g. Salary, Bread, Milk)
2. Enter Amount
3. For Expense, use negative number(e.g. -500)
4. Click **Add Transaction**

## How to Run

Just open `index.html` in your browser.
No need to install anything.
